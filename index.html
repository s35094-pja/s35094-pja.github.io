About this website

This website is a student project inspired by the aesthetic of high fashion editorials. It presents selected themes connected with the House of Versace: identity, accessories, and the visual culture of the atelier.

The design uses a clean layout, strong contrast, large typography, simple transitions and a responsive structure for different screen sizes.

Fashion is not only about clothes. It is also about image, detail, silhouette, texture, memory and visual storytelling.

Design mood

Sharp contrast. Editorial rhythm. Minimal forms. Dramatic presence.

The style of this project is intentionally simple, monochrome and modern.
